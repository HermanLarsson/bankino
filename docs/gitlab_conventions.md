GitLab Practices and Conventions

Branch Naming:
Branches should be named exactly after the task it represents in Jira. It should be the Task ID followed by the description.  
E.g: SCRUM-41-display-existing-accounts

Commit messages:
Should start with the task ID, a colon, and then a clear and short description of what changes have been made.
E.g: “SCRUM-41: Function for reading user account information from JSON files implemented.”
